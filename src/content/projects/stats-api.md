The Brawlhalla Stats API is [Blue Mammoth Games](https://bluemammoth.com/about/) esports REST API. It gives developers the ability to view data from almost every Brawlhalla tournament that exists, as well as the player data the tournaments collect. The website serves an average of 1,500 page hits daily.

I drafted the documentation and website during my first contract that went from August 2023 to November 2023. It was created with the [Astro](https://astro.build/) framework, and the pages primarily in Markdown. I used [Postman](https://www.postman.com/) to catalogue and test the APIs.
