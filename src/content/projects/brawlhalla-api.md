The Brawlhalla API is [Blue Mammoth Game's](https://bluemammoth.com/about/) premier REST API. It allows developers to tap into a veritable goldmine of in-game statistics, including win-loss rate, ranked leaderboards, complete guild data, and more. The API serves over 100,000 calls daily, and the website serves an average of 4,000 page hits daily.

I drafted documentation for version 1.0 (alongside verifying and updating the previously existing version 0.0) and created the website during my second contract that went from January 2025 to January 2026. It was created with Astro's documentation theme [Starlight](https://starlight.astro.build/). The pages were primarily written in Markdown, and I used [HTTPie](https://httpie.io/) to catalogue and test the APIs.
