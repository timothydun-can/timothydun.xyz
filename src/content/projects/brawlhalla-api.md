The Brawlhalla API is [Blue Mammoth Games](https://bluemammoth.com/about/) premier REST API. It allows developers to tap into a veritable goldmine of in-game statistics, including win-loss rate, ranked leaderboards, complete guild data, and more. The API serves over 100,000 calls daily, and the website serves an average of 4,000 page hits daily.

I drafted documentation for version 1.0 (alongside verifying and updating the previously existing version 0.0) and created the website during my second contract that went from January 2025 to January 2026. It was created with the Astro documentation theme [Starlight](https://starlight.astro.build/). The pages were primarily written in Markdown, and I used [HTTPie](https://httpie.io/) to catalogue and test the APIs.

Additionally, I drafted a promotional/informational email sent to users of version 0.0 to both promote the new version and inform them of the impending deprecation process. That email can be found on [this page](brawlhalla-api-email).
