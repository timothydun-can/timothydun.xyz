Gjallarhorn is a program [Blue Mammoth Games](https://bluemammoth.com/about/) offers to community members that host tournaments. Gjallarhorn allows such organizers to quickly create JSON files that include player information and character images to use in tournament graphics.

I created the README.md file during my first contract that went from August 2023 to November 2023.
